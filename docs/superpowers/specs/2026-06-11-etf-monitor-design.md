# ETF 实时监控工具设计文档

## 概述

A股场内QDII ETF 实时价格与溢价率监控工具，支持声音阈值提醒。工具位于 `web-tools/etf-monitor/`，采用单 HTML 文件结构（Vanilla JS）。

## 功能需求

1. **实时行情展示**：展示约10只标普500/纳斯达克 QDII ETF 的实时价格、涨跌幅、溢价率
2. **声音提醒**：当价格或溢价率达到设定阈值时触发 Web Audio API 蜂鸣声
3. **自定义配置**：支持添加/删除 ETF、设置每只 ETF 的独立提醒阈值
4. **数据持久化**：通过 localStorage 保存配置

## 数据源

- **主数据源**：东方财富 push2 API（JSONP 方式）
  - 行情接口：`https://push2.eastmoney.com/api/qt/stock/get`
  - 参数：`secid=1.{code}&fields=f43,f44,f45,f46,f47,f48,f50,f57,f58,f170,f171`
  - f43=最新价, f57=代码, f58=名称, f170=涨跌幅, f171=涨跌额
- **备用数据源**：新浪财经 hq.sinjs.cn API（script tag 方式）
  - `https://hq.sinajs.cn/list=sh{code},sz{code}`
- **净值数据**：通过东方财富基金接口获取最新净值，计算溢价率
- **刷新策略**：
  - 交易时段（9:30-11:30, 13:00-15:00）：每10秒刷新
  - 非交易时段：停止自动刷新，显示最后数据

### 每张ETF卡片内容

- 名称（如"标普500ETF"）
- 代码（如"513500"）
- 当前价（粗体大字号）
- 涨跌幅（红色+↑ / 绿色+↓）
- 溢价率（橙色高亮当超过阈值）
- 点击卡片 → 展开/收起该ETF的独立阈值设置

## 提醒系统

### 触发条件

每10秒轮询检查：
1. **溢价率阈值**：`abs(溢价%) >= 设定值` → 触发
2. **价格阈值**：`abs(涨跌幅%) >= 设定值` → 触发

### 声音实现

- 使用 Web Audio API 合成音（与 interval-timer 一致的方式）
- 溢价率预警：高频急促短音（800Hz, 重复3次）
- 价格预警：低频长音（400Hz, 持续1秒）
- 防抖机制：同一ETF同类型提醒触发后，60秒内不重复

### 全局控制

- 音效总开关
- 支持一次性确认（通过 Notification API 权限）

## 数据持久化

localStorage 存储结构：

```json
{
  "etfs": [
    { "code": "513500", "market": "sh", "enable": true,
      "premiumAlert": 5, "priceAlert": 3 }
  ],
  "globalSettings": {
    "soundEnabled": true,
    "defaultPremiumAlert": 5,
    "defaultPriceAlert": 3,
    "refreshInterval": 10
  }
}
```

## 技术决策

- **单 HTML 文件**（Vanilla JS），无需构建工具
- **CSS Grid/Flexbox** 响应式布局
- **JSONP + script tag** 解决跨域数据获取
- **Web Audio API** 合成声音，无需外部音频文件
- **localStorage** 持久化配置
